Public homepage for https://bumblev95.github.io/.

The root page shares CSS, JavaScript and market datasets from [bumblev95/S-P-500-](https://github.com/bumblev95/S-P-500-). Its `index.html` mirrors that repository's homepage with an absolute `<base href="https://bumblev95.github.io/S-P-500-/">` so existing assets and navigation keep working.

Google AdSense account ownership uses publisher `ca-pub-9723666081819297`. Advertising is disabled in the shared configuration pending site approval, ad-unit identifiers, hosting and privacy setup.

GitHub Pages publishing source: `main` branch, `/(root)` folder. `.nojekyll` serves these static files directly.

When the source homepage HTML changes, update this homepage while preserving the base URL. Shared asset and data updates are loaded automatically.
