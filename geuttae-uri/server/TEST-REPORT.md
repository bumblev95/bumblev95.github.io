# 그때 우리 검증 기록

## v0.3.2 출제 도움 연결 준비 — 2026-10-13 UTC

- 서버 자동 검사 73개(기존 52 + 신규 21), 저장/템플릿 검사 7개 통과. 설치 SDK의 Responses 요청은 모의 fetch로 검사했으며 실제 OpenAI 요청은 0회다.
- 새 검사: 별도 텍스트 전송 동의, 사진/구매 플래그 차단, 직접 적은 정답/이야기 보존, 자동 제출 금지, 비공개 초안, 같은 요청 ID 한 번 처리, 동시 요청의 모임 공유 한도, 여러 방/재시작을 포함한 UTC 하루 시도 상한, 실패/시간 초과의 성공 횟수 반환, 게임 시작·퇴장·종료·만료 중 생성 취소와 초안 접근 차단.
- 독립 브라우저 QA에서 모의 AI 생성 → 적용 전 기존 내용 보존 → 초안 적용 → 확인/저장 동의 다시 꺼짐 → 직접 수정 후 재확인 → JPG와 문제 제출을 통과했다. 네트워크 실패 후 기존 작성 내용 보존, 무료 질문 시작 버튼, AI 미사용 표시가 있는 고정 예시, 320/390/768/1440 폭을 확인했다.
- 현재 공개 AI 연결은 꺼져 있다. 모델 선택·API 키 생성·실제 AI 비용·결제·광고 SDK·Ultimate 사용 권한은 이번 패치에서 활성화하지 않았다. 공급자 결과 품질·지연·계정 접근·실제 과금은 미검증이다.
- 가상 친구 체험의 퀴즈·동의·추억집 3종/색상 3종·HTML 저장·브라우저 인쇄와, 별도 HTTPS 정적/API origin에서 두 독립 모바일 브라우저의 실제 업로드·SSE·재접속·게임 완료·동의된 추억집 전달 회귀를 확인했다.
- 기존 릴리스·root 홈페이지·광고·sitemap을 수정하지 않았다. 새 릴리스만 0.3.2 디렉터리에 추가한다.

## v0.3.1 멀티플레이·추억집 통합 기록

검증일: 2026-10-13 UTC (Regina 10월 12일). 실제 수행한 범위만 기록한다.

- 최신 공개 main v0.2.2를 멀티플레이 PR #4에 통합한 v0.3.1. 기존 v0.2.0/0.2.1/0.2.2 릴리스와 root 홈페이지는 수정하지 않았다.
- 서버 자동 검사 52개, 템플릿/내보내기 검사 7개가 통과했다. 서버 HTTP/SSE, 승인 전/타 방 접근 차단, 사진 소유자, 출제자 득점 제외, 중복 답변, 공동 우승, 재접속/재시작, 사진 삭제, 만료, 호스팅 설정을 검사한다.
- 새 검사: 저장 동의 기본 꺼짐, boolean 검증, 소유자만 변경, 동의 철회, 허용/미허용 사진 혼합, 완료 시 호출자와 승인된 SSE 참가자의 동일 추억집, 실제 사진 파일 및 저장된 이야기 제거, 새 state/재접속에서 추억집 재전송 없음, 신고/중도 종료 저장 제외, 불러오지 못한 사진 처리.
- 실제 서버를 띄운 별도 HTTPS 정적/API origin에서 독립 모바일 브라우저 두 개로 방 생성 → 승인 → 각각 JPG/문제 등록 → 출제자 교대 → 재접속 → 동점 결과 → 허용 추억집 저장을 수행했다. 한 사람의 사진/이야기는 저장 불허로 제외했다. 두 참가자 모두 동일하게 허용된 추억집을 받았다.
- 두 참가자의 내보낸 HTML에서 허용한 이야기 포함, 불허 사진·문제·이야기/방 코드/토큰/API 주소/스크립트 제외, 오프라인 열기와 PDF 인쇄를 확인했다. 실제 참가자를 가상 참가자로 표시하지 않는다.
- 3종 디자인과 모바일 폭 320/390/768/1440, 업데이트 적용 보류, 새로고침 시 완료 추억집 제거, 홈 이동 확인을 검사했다. 가상 친구 체험도 전체 저장/인쇄 회귀 검사를 통과했다.
- 한글 폰트로 생성한 체험 PDF 3개(각 4쪽), 실제 서버 테스트 PDF 1개(3쪽)의 총 15쪽을 이미지로 렌더링해 확인했다. 테스트용 JPG는 단색 fixture이며 실제 사용자 사진이 아니다.
- 공개 서버 계정 연결/API 도메인, 실제 볼륨의 백업 제외, 실제 휴대폰 두 대의 인터넷 플레이는 아직 미확인. runtime-config.json의 apiBase:null을 유지하고 PR은 Draft로 둔다.
- 종료 시 서버 사진을 삭제하므로 추억집은 종료 순간 연결된 탭에만 전달된다. 완료 후 새로고침/탭 종료하면 다시 받을 수 없다. 내려받은 파일은 사용자 기기에 남는다.
- 실제 결제/광고 SDK/보상형 광고/AI/스토어 배포/Ultimate 요금제는 이번 구현 범위가 아니다. US$0.99는 출시 예정 가격이며 현재 저장은 무료 체험이다.

## Railway 운영 확인 — 2026-10-13 Regina

- 테스트 서버는 실제 배포 SUCCESS와 HTTPS healthcheck 통과 상태다. 배포된 API에서 두 독립 참가자의 승인·업로드·SSE·재접속·출제 교대·동점·동의된 추억집 전달·종료 후 사진 접근 차단을 통과했다.
- 인증된 Railway 대시보드에서 Trial 계정 상태와 무료 크레딧 정책을 확인했다. 유료 요금제 전환이나 결제를 실행하지 않았다. Trial 크레딧 소진 시 서버가 중단될 수 있다.
- 사진 볼륨의 Backups 페이지는 `No Backups`를 표시했다. 현재 요금제에서는 새 백업, 자동 일정, PITR를 만들 수 없다.
- 실행 중인 컨테이너에서 집계만 읽었다. `/data`와 앱 데이터 디렉터리는 0700이며 서비스 Node 프로세스는 UID 1000이다. 점검한 종료 방 4개의 JPG 파일은 0개, 삭제 대기는 0개다. 사진·이야기·방 코드·접근 키를 출력하지 않았다. 만료 24시간의 실시간 경과나 클라우드 제공자 내부 매체 전체 삭제까지 검증했다는 의미는 아니다.
- 사용자는 테스트 주소에서 정상 동작한다고 확인했다. 기기 수/네트워크 조건은 명시하지 않았으므로 실제 휴대폰 두 대 QA 완료로 기록하지 않는다.
- 고정 Pages 연결 후보에는 검증된 API origin만 설정했다. 실제 게시 완료는 병합 커밋의 Pages 파일 일치/브라우저 검사와 고정 주소에서의 참가 검증 결과를 기준으로 확인한다.
