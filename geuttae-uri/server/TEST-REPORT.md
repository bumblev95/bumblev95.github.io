## Railway 운영 확인 — 2026-10-13

- 테스트 서버는 실제 배포 SUCCESS와 HTTPS healthcheck 통과 상태다. 배포된 API에서 두 독립 참가자의 승인·업로드·SSE·재접속·출제 교대·동점·동의된 추억집 전달·종료 후 사진 접근 차단을 통과했다.
- 인증된 Railway 대시보드에서 Trial 계정 상태와 무료 크레딧 정책을 확인했다. 유료 요금제 전환이나 결제를 실행하지 않았다. Trial 크레딧 소진 시 서버가 중단될 수 있다.
- 사진 볼륨의 Backups 페이지는 `No Backups`를 표시했다. 현재 요금제에서는 새 백업, 자동 일정, PITR를 만들 수 없다.
- 실행 중인 컨테이너에서 집계만 읽었다. `/data`와 앱 데이터 디렉터리는 0700이며 서비스 Node 프로세스는 UID 1000이다. 점검한 종료 방 4개의 JPG 파일은 0개, 삭제 대기는 0개다. 사진·이야기·방 코드·접근 키를 출력하지 않았다. 만료 24시간의 실시간 경과나 클라우드 제공자 내부 매체 전체 삭제까지 검증했다는 의미는 아니다.
- 사용자는 테스트 주소에서 정상 동작한다고 확인했다. 기기 수/네트워크 조건은 명시하지 않았으므로 실제 휴대폰 두 대 QA 완료로 기록하지 않는다.
- 고정 Pages 연결 후보에는 검증된 API origin만 설정했다. 실제 게시 완료는 병합 커밋의 Pages 파일 일치/브라우저 검사와 고정 주소에서의 참가 검증 결과를 기준으로 확인한다.
