# v0.3.1 검증 기록

검증일: 2026-10-13 UTC (Regina 10월 12일). 실제 수행한 범위만 기록한다.

- 최신 공개 main v0.2.2를 멀티플레이 PR #4에 통합한 v0.3.1. 기존 v0.2.0/0.2.1/0.2.2 릴리스와 root 홈페이지는 수정하지 않았다.
- 서버 자동 검사 52개, 템플릿/내보내기 검사 7개가 통과했다. 서버 HTTP/SSE, 승인 전/타 방 접근 차단, 사진 소유자, 출제자 득점 제외, 중복 답변, 공동 우승, 재접속/재시작, 사진 삭제, 만료, 호스팅 설정을 검사한다.
- 새 검사: 저장 동의 기본 꺼짐, boolean 검증, 소유자만 변경, 동의 철회, 허용/미허용 사진 혼합, 완료 시 호출자와 승인된 SSE 참가자의 동일 추억집, 실제 사진 파일 및 저장된 이야기 제거, 새 state/재접속에서 추억집 재전송 없음, 신고/중도 종료 저장 제외, 불러오지 못한 사진 처리.
- 실제 서버를 띄운 별도 HTTPS 정적/API origin에서 독립 모바일 브라우저 두 개로 방 생성 → 승인 → 각각 JPG/문제 등록 → 출제자 교대 → 재접속 → 동점 결과 → 허용 추억집 저장을 수행했다. 한 사람의 사진/이야기는 저장 불허로 제외했다. 두 참가자 모두 동일하게 허용된 추억집을 받았다.
- 두 참가자의 내보낸 HTML에서 허용한 이야기 포함, 불허 사진·문제·이야기/방 코드/토큰/API 주소/스크립트 제외, 오프라인 열기와 PDF 인쇄를 확인했다. 실제 참가자를 가상 참가자로 표시하지 않는다.
- 3종 디자인과 모바일 폭 320/390/768/1440, 업데이트 적용 보류, 새로고침 시 완료 추억집 제거, 홈 이동 확인을 검사했다. 가상 친구 체험도 전체 저장/인쇄 회귀 검사를 통과했다.
- 한글 폰트로 생성한 체험 PDF 3개(각 4쪽), 실제 서버 테스트 PDF 1개(3쪽)의 총 15쪽을 이미지로 렌더링해 확인했다. 테스트용 JPG는 단색 fixture이며 실제 사용자 사진이 아니다.
- 공개 서버 계정 연결/API 도메인, 실제 볼륨의 백업 제외, 실제 휴대폰 두 대의 인터넷 플레이는 아직 미확인. runtime-config.json의 apiBase:null을 유지하고 PR은 Draft로 둔다.
- 종료 시 서버 사진을 삭제하므로 추억집은 종료 순간 연결된 탭에만 전달된다. 완료 후 새로고침/탭 종료하면 다시 받을 수 없다. 내려받은 파일은 사용자 기기에 남는다.
- 실제 결제/광고 SDK/보상형 광고/AI/스토어 배포/Ultimate 요금제는 이번 구현 범위가 아니다. US$0.99는 출시 예정 가격이며 현재 저장은 무료 체험이다.
