# v0.3.0 검증 기록

검증일: 2026-10-11. 이 기록은 실제 확인한 범위만 표시한다.

- v0.1 ZIP의 `src/logic.mjs`와 v0.2.0 `logic.js`는 동일했다. 31개 기존 테스트를 가져오고 서버·클라이언트가 v0.3.0 규칙 파일 하나를 공유하도록 했다.
- 로컬 Node 실행에서 자동 테스트 **37개 통과**. 실제 HTTP와 SSE 서버에 독립된 세션을 연결했다. 원본 환경의 networkInterfaces 조회 제한은 안전한 fallback으로 해결했다.
- 승인 전 상태·사진 접근, 방장 권한, 다른 방·사진 소유자 검증, 공개 전 정답·스토리 은닉, 출제자 답변 금지, 동시 중복 답변, 동점 결과, 종료·신고·퇴장 삭제, 서버 재시작 복원, 방문자 없이 만료 정리, 정확한 Pages CORS origin·Bearer 인증을 검증했다.
- 프런트·서버 JavaScript 구문과 Git diff 공백 검사를 통과했다. v0.2.0 릴리스, 기존 boot-v1.js와 다른 홈페이지 콘텐츠는 수정하지 않았다.
- CI 브라우저 시나리오는 실제 업로드/SSE를 사용하고, 별도 HTTPS 정적 프런트/API origin과 격리된 390px·360px 모바일 브라우저 컨텍스트로 실행하도록 추가했다. **GitHub Actions run 38163260118에서 브라우저 검증 통과**. 이 실행은 최초 36개 테스트 커밋 기준이며, 이후 JPEG 메타데이터 강화로 37개가 됐다.
- 이 실행 환경에서는 지원되는 브라우저 제어 도구가 없어 로컬 브라우저 QA를 실행하지 않았다. CI 브라우저 결과는 실제 휴대폰 두 대의 검증을 대체하지 않는다.
- 공개 서버 배포, 실제 API 도메인, 볼륨의 백업 제외와 실운영 24시간 정리는 **미확인**. Pages runtime-config.json의 apiBase는 null로 남겨 두었다.
- AI 자동 출제·성인 모드·스토어 배포는 구현 또는 검증한 기능으로 표시하지 않는다.
